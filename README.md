🎥 YouTube Clone Landing Page

A responsive YouTube-inspired web interface built using HTML5 and CSS3. This project recreates the basic layout and user experience of a video streaming platform, including video recommendations, category navigation, Shorts section, search bar, and footer.

🚀 Live Demo

View Live Project :- https://you-tube-web-olive.vercel.app/

✨ Features

- Responsive Navigation Bar
- Search Bar with Search Icon
- Category Navigation Buttons
- Featured Video Cards
- Shorts Section
- Recommended Videos Section
- Hover Effects on Cards
- Responsive Flexbox Layout
- Clean and Modern UI Design

🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome Icons

🎯 Project Objective

The objective of this project is to practice front-end web development by recreating a simplified version of YouTube's user interface. The project focuses on layout design, responsive web development, styling techniques, and user experience principles.

📚 Learning Outcomes

- Building responsive web pages
- Working with Flexbox layouts
- Creating navigation menus
- Designing video card components
- Implementing hover effects and transitions
- Structuring content using semantic HTML
- Improving CSS styling and layout skills

📸 Preview

The website includes a navigation bar with a search feature, category filters, video recommendation cards, a Shorts section, and additional content sections inspired by YouTube's layout.

🚀 Future Improvements

- Functional Search Feature using JavaScript
- Dark Mode Toggle
- Video Player Integration
- User Authentication
- Responsive Mobile Navigation Menu
